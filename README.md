## Datenschutz

- Keine Cookies, kein Tracking, keine externen Schriften oder Skripte (Systemschriften)
- `noindex, nofollow`: Die Seite wird gezielt per Link weitergegeben, nicht über Suchmaschinen gefunden
- Keine privaten Daten im Code
- Hosting über GitHub Pages; GitHub protokolliert laut eigener Dokumentation die IP-Adressen der Besucher
